# Diabetes Data Analysis

## Overview
A data analysis project exploring the relationship between diabetes and several key health factors — pregnancies, age, and Body Mass Index (BMI) — using Power Query for data preparation and Power BI for interactive visualization.

## Problem Statement
This project investigates the relationship between diabetes diagnosis and:
- Number of pregnancies
- Age
- Body Mass Index (BMI)

## Workflow

### 1. Data Collection
Imported the diabetes patient dataset for analysis.

### 2. Data Transformation
Applied initial transformation steps to prepare the raw data for further processing.

### 3. Data Cleaning & Preparation (Power Query)
Used Power Query to perform extensive data cleaning and restructuring, including:
- Handling missing or invalid values
- Categorizing columns (e.g., age groups, BMI categories)
- Reshaping tables to support analysis

### 4. Dashboard Creation (Power BI)
Built an interactive dashboard displaying:
- Diabetes distribution across age groups
- Relationship between BMI and diabetes rate
- Impact of pregnancy count on diabetes outcomes
- Interactive visuals and KPIs for data exploration

## Tools Used
- **Power Query** — Data cleaning and transformation
- **Power BI** — Interactive dashboard and visualization

## Key Insights
- Higher BMI is associated with a higher likelihood of diabetes
- A higher number of pregnancies is associated with a higher likelihood of diabetes
- 70% of individuals with high glucose levels are diagnosed with diabetes

## Project Files
- `Diabetes_Dataset.csv` — Raw dataset
- `Diabetes_Analysis.pbix` — Full Power BI file with dashboard
